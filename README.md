# bilingual-rag-support-assistant
A bilingual (Arabic/English) RAG-based IT support assistant built with n8n, using vector embeddings to answer employee questions from an approved knowledge base. 

## SDAIA Academyٍ

[SDAIA Academy Repository](https://github.com/SDAIAAcademy)

## Project Files

- **Document Ingestion.json** — Workflow that loads knowledge-base documents, generates embeddings, and stores them in a vector store.
- **Ai Agent.json** — The RAG-based AI Agent workflow that retrieves relevant information and answers user questions.
